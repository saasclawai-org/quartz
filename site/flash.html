⚡ Flash Quartz from your browser

Plug in your ESP32 board, click one button. No Python, no drivers, no terminal.

Works with Chrome, Edge, and Opera on desktop (needs Web Serial). On Firefox/Safari? Use the manual instructions.

ESP32-C3 · recommended

The $3 Super Mini. Best value miner — the board most Quartz miners start with. Firmware v072.

ESP32 (classic)

Original ESP32 / WROOM boards, M5Stack Core. Firmware v074.

ESP32-S3

S3 boards (DevKitC, Feather S3). Firmware v074.

Fresh install erases the chip and sets up everything (use it on new boards).
Update app only rewrites just the application and preserves your wallet & WiFi settings. If the dialog asks about erasing, choose Keep.

  1. Plug the board in via USB. If it has a data/charge switch, use data — many cables are charge-only and won't work.
  2. Click a flash button above and pick the port (USB Serial on Windows, /dev/ttyUSB* or /dev/ttyACM* on Linux/Mac).
  3. Wait for the success screen (~1–2 minutes). The board reboots into Quartz automatically.
  4. Connect to WiFi: on first boot the board shows a Quartz-XXXX setup network — join it from your phone to configure your WiFi, then it starts mining.

Stuck? The board isn't listed, or flashing fails? See Setup Help or the manual esptool instructions.
