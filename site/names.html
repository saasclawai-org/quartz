Register your own name

A name is just an on-chain message: sent from the address being named, to name:registry, with text NAME:REGISTER|LABEL:Your Name|KIND:miner. On mainnet the sender is signature-verified — only the address owner can name it.

curl -sO https://quartzchain.net/name_register.py python3 name_register.py --address YOUR_ADDRESS --label "Your Name" --kind miner # Look up any address: python3 name_register.py --lookup YOUR_ADDRESS
