How It Works

Three layers turn a $5 chip into an autonomous economic agent.

📋

Rule Engine

Define triggers and actions in firmware. "If solar output > 5W, pay relay node 0.001 QZ for bandwidth." Rules are deterministic, auditable, and run on-device — no external API calls.

🧠

TinyML

On-chip machine learning with TensorFlow Lite Micro. Sensors feed a lightweight model that predicts conditions (weather, demand, prices) and adjusts behavior — all within 4MB of flash.

⚡

Actuation

GPIO pins trigger real-world actions: flip a relay, open a valve, send a LoRa packet, display a QR code. The agent observes, decides, and acts — all without phoning home.

Not AGI. A thermostat with a wallet.

Quartz agents aren't trying to be smart. They're trying to be useful. A simple rule — "pay 0.001 QZ when the soil is dry" — doesn't need a language model. It needs a sensor, a wallet, and a relay. That's what a $5 ESP32 provides.

ESP32 with e-paper display shows a dynamic QR code. Customer scans, pays QZ. Agent verifies on-chain and dispenses product or unlocks access. Full point-of-sale for under $10.

Agent relays blocks and transactions for other Quartz nodes. Earns micro-fees per packet relayed. Solar-powered repeaters extend mesh coverage to 15km — no monthly ISP bill.

Solar panel agent sells excess energy to battery agent. Battery agent sells stored power to mining agent. Mining agent pays relay agent for bandwidth. A closed-loop economy with zero human intervention.

Dual-Use Architecture

The ESP32's two cores split the work. Your app runs on one, Quartz runs on the other.

Core 0 · 240 MHz

🟣 Your Application

  • Sensor reads (I2C, SPI, ADC)
  • Display & UI (e-paper, OLED)
  • GPIO actuation (relays, valves)
  • TinyML inference
  • Business logic & rules engine
  • LoRa / WiFi transport
⇌
Core 1 · 240 MHz

🟢 Quartz Engine

  • Wallet & key management (PUF-seeded)
  • Transaction signing (WOTS+)
  • Block validation & chain sync
  • Mining (CrystalHash + PUF)
  • Balance & UTXO tracking
  • Mesh gossip protocol

Both cores share 520KB SRAM and 4MB+ flash. FreeRTOS schedules tasks on each core independently. Your app never blocks the blockchain — the blockchain never blocks your app.
