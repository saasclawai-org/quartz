Emission Decisions

What changed from the original design and why.

Supply Retune (Aug 2026)

Base emission set to 42 QZ/block with 500,000-block halving, making total supply land exactly on 42,000,000 QZ (42 × 500,000 × 2). The original 50 QZ / 210K schedule never matched the 42M figure — this was the last paper-vs-chain drift.

A 1.2% emission trim, not an expansion. Decided before the first halving, so no historical schedule was rewritten.

Dev Fund: Killed

Zero percent. No premine, no ICO, no founder allocation. 100% of block rewards go to miners. The quantum security pool was also dropped — a protocol tax minting to an address with no spender is dead supply.

Mesh Relayer Pool: Deferred

Design preserved, payment deferred. 10% of block reward activates only at a future hard fork — and only when a real mesh fleet carries live traffic with validated relay-share accounting. Paying it before that would mint to nothing.

Early Adopter Bonus: Removed

The originally-planned 2x bonus for the first 1,000 PUF devices paid above the coinbase schedule, which the consensus engine correctly rejects. Fair launch means one schedule for everyone, from block 1.

⏳

Founder Timelock

Quartz has no dev fund, no premine, and no ICO. The founders mine on exactly the same terms as everyone else — PUF-attested ESP32 hardware, same block rewards, same difficulty.

To demonstrate long-term commitment and prevent any appearance of a dump, any blocks mined by founder-identified wallets will be timelocked for 2 years from mainnet genesis — enforced in consensus code before mainnet launch. Once live, these coins cannot be transferred, staked, or sold until the timelock expires. (Testnet founder coins are not yet locked; the timelock ships with the mainnet code.)

This is a voluntary, transparent commitment recorded on-chain. Founder wallets are publicly identified. After the 2-year period, the coins are fully liquid — no special privileges, no admin keys, no escape hatches.

Key point: The timelock is a social commitment encoded in the reference wallet software. The protocol itself does not special-case founder addresses. Anyone can verify founder wallet balances and timelock heights on the explorer.
