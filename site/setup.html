🔮 Quartz Setup Guide

Flash → Connect WiFi → Write down seed → Mine. About 5 minutes.

1. Flash firmware → 2. Connect WiFi → 3. Write down seed → 4. Set PIN (optional) → ⛏️ Mining
1Flash the Firmware

Download the firmware binaries from the download page. You need three files:

  • bootloader-v063.bin
  • partition-table-v063.bin
  • quartz-app-v063.bin
Windows
macOS
Linux
  1. Install CP210x USB driver (or CH340 driver for some boards)
  2. Install Python: python.org (check "Add to PATH")
  3. Open Command Prompt, install esptool: pip install esptool
  4. Plug ESP32 into USB. Open Device Manager → Ports (COM & LPT) → find your COM port (e.g. COM6)
  5. Flash all three partitions:
python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash ^
  0x1000 bootloader-v063.bin ^
  0x10000 partition-table-v063.bin ^
  0x20000 quartz-app-v063.bin

Use ^ for line continuation on Windows (or put it all on one line).

  2. Install Python and esptool: pip install esptool

First-time setup vs updates:
  • First flash (new device): Use the three-part command above. This writes the bootloader, partition table, and app — fresh install.
  • Update (keep wallet): Flash only the app at 0x20000 — your wallet and seed phrase survive the update: 
    python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash 0x20000 quartz-app-v063.bin
  • Full reset (wipe wallet): Erase everything first, then flash all three: 
    python -m esptool --chip esp32 --port COM6 erase_flash
python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash ^
  0x1000 bootloader-v063.bin ^
  0x10000 partition-table-v063.bin ^
  0x20000 quartz-app-v063.bin

Wait for Hash of data verified. for each segment. When done, press the RESET button on the ESP32 (or unplug/replug).

2Connect to WiFi

The ESP32 needs WiFi to reach the mining node. On first boot (or after a full erase), it creates a setup hotspot:

  1. On your phone or computer, go to WiFi settings
  2. Connect to Quartz-XXXX (no password) — the last 4 characters are from the device's MAC address
  3. A setup page should pop up automatically (captive portal)
  4. If not, open a browser → go to 192.168.4.1
  5. Enter your home WiFi name and password
  6. Click "Start Mining ⚡"

The device reboots, connects to your WiFi, and generates a new wallet. You'll see the connection status on the display (M5Stack) or in the serial log.

WiFi is for mining only. Your seed phrase is never transmitted over WiFi — it's shown via serial console or BLE only.

If WiFi credentials are already saved in the device, it skips the hotspot and connects automatically on boot.

3Write Down Your Seed Phrase

On first boot with a new wallet, the device generates a 12-word BIP39 seed phrase. This is your wallet's master key — anyone with these words controls your wallet.

The seed is shown on the serial console. Open a serial terminal to see it:

  2. Connection type: Serial

  4. Speed: 115200

⚠️ Write them on paper. Not a screenshot. Not a text file.
  • Order matters — word 1 is word 1
  • Keep the paper somewhere safe and offline
  • Anyone with these 12 words can spend your coins
  • If you lose the paper, your coins are gone if the device breaks
Lost your paper? Type seed in the serial console to re-display the 12 words (PIN-gated if a PIN is set — see step 4).
4Set a PIN (Recommended)

A PIN protects the seed command — without a PIN, anyone with USB access can re-display your 12 words. With a PIN, they get 10 wrong guesses before the wallet is wiped.

In the serial console, type:

setpin 1234

Replace 1234 with your own 4-8 digit PIN.

You should see: ✅ PIN set

From now on, seed requires you to unlock first:

pin 1234       ← unlock (resets after power cycle)
seed           ← now shows your 12 words
⚠️ 10 wrong PINs = wallet wiped. The counter persists across reboots — power-cycling does NOT reset it. If you forget your PIN, the only way to recover is your 12-word seed phrase (flash a new device, import words).
✓That's it. You're mining.

Your ESP32 is now mining Quartz. Check your balance at the web wallet — import your 12 words to see your address and balance.

  • 📊 M5Stack (with screen): Stats on display — hash rate, blocks, uptime, device ID
  • 📱 Android app: Connect via Bluetooth to see live stats and send transactions
  • 💻 Serial console: Mining log (once per minute), block finds, commands

Serial Commands

Available anytime while mining (type in the serial console, characters echo back):

help                  Show available commands
setpin <digits>       Set a 4-8 digit PIN (first time) or change PIN (unlock first)
pin <digits>          Unlock the serial session (required for 'seed' if PIN is set)
seed                  Re-display your 12-word seed phrase (PIN-gated)
pinstatus             Show PIN status, failed attempts, and lock state
confirm               Acknowledge seed display on first boot

FAQ

What's the difference between app-only flash and full flash?

App-only (0x20000): Updates firmware, keeps your wallet, seed, PIN, and WiFi settings. Use for updates.

Full flash (all three partitions): Writes bootloader + partition table + app. Use for first install or if the partition table changed.

Erase + flash: Wipes everything including NVS (wallet, seed, PIN, WiFi). Device generates a fresh wallet on next boot. Use to reset to factory state.

I can't type in the serial console — nothing appears

The firmware echoes characters back to the terminal. If you see nothing while typing:

  • Make sure PuTTY flow control is set to None (not XON/XOFF)
  • Check you're on the right COM port and baud rate (115200)
  • Press RESET on the ESP32 — you should see boot messages
  • Type help + Enter — you should see the command list

The mining log is too noisy — I can't see what I type

The mining log prints once per minute. If you're seeing more frequent output, you may be on an older firmware. Update to the latest version.

I missed the seed display — can I see it again?

Yes. Type seed in the serial console. If a PIN is set, unlock first with pin <digits>.

If you haven't confirmed yet, power-cycle the device — the seed shows again on every boot until you type confirm.

What if I lose the paper with my seed phrase?

Your funds are at risk. If you still have the device and know your PIN, type seed to re-display the words and write them down again. If the device is lost or the PIN is forgotten, the coins are gone.

Can I use the same seed on multiple devices?

Not recommended — each device should have its own wallet and mine to its own address. But for recovery: flash a new device, erase NVS, and the new device generates its own wallet. To restore a lost wallet, use the web wallet's Import feature with your 12 words.

Are the 12 words compatible with other wallets?

Yes. The firmware uses standard BIP39 + BIP44 (derivation path m/44'/789'/0'/0'/0') with Ed25519 keys. Import the same 12 words in the web wallet and you'll get the same address and key.

Do I need to keep the ESP32 plugged in?

For mining: yes (needs power + WiFi). For wallet recovery: no — import your 12 words in the web wallet to access your funds from any browser.

What baud rate?

115200 — 8 data bits, no parity, 1 stop bit (8N1). Flow control: None.

What boards are supported?

Any classic ESP32 with 4MB+ flash: M5Stack Core, Heltec V3, ESP32 DevKit, NodeMCU-32S, LOLIN D32, TTGO T-Display. ESP32-S3 and ESP32-C3 need separate builds (see download page).
