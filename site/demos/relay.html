🔌 Pay-to-Trigger Relay

Coin-op for the physical world: pay testnet QZ and the relay clicks — unlock a gate, start a charger, open a valve. No accounts and no API keys: the payment itself is the switch.

relay-01

Real hardware. A Quartz board with a relay module watches this wallet on-chain — your payment closes the circuit, in the browser and in the flesh. The board mines with this wallet too; mining rewards never trigger the relay — only payments do.

Waiting for payment…
1. Scan / pay from the Quartz wallet (testnet faucet inside)
2. Detection is on-chain — this page watches the block data
3. The relay trips and the session timer starts; the trigger is recorded on-chain to you
RELAY CLOSED — LOAD ENERGIZED
10:00

This relay's wallet is a real board wallet — it mines and takes payments on the same address (rewards are filtered out; only payments trip the relay). Want your own? demos/pay_demo.py on GitHub runs the same flow on any Raspberry Pi GPIO.
