Machine payments you can poke right now — live on testnet, no signup. Testnet QZ is free: grab some from the faucet inside the web wallet, then pay a machine and watch the chain do the rest.

Pay-per-Read Sensor

A cold-chain sensor sells its data instead of publishing it. Pay 0.1 QZ and the temperature reading is delivered on-chain to you — the payment itself is the auth. No accounts, no API keys.

Pay-to-Trigger Relay

Coin-op for the physical world. Pay QZ and the relay clicks — gate, charger, water valve. Watch it trip, run the session timer, and record the trigger on-chain. Same flow drives a real GPIO relay on a Pi or ESP32.

Village LLM

A Raspberry Pi sells local-AI completions for QZ — pay-per-prompt with no escrow. The payment is an ordinary on-chain transaction; the answer arrives with an Ed25519-signed receipt anyone can verify offline. The “solar-powered village LLM.”
