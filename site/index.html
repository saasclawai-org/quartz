How Quartz Mining Works

Every block requires proof from a physical ESP32 chip. No hardware = no mining. From block 1.

🔐

PUF Hardware Binding

SRAM PUF reads genuine silicon entropy on cold boot. Unique per chip, unclonable, not stored anywhere. No PUF = no valid block.

🚫

GPU-Proof

Every block needs a PUF attestation response that only a physical ESP32 can produce. A GPU farm with zero chips produces zero blocks.

💚

Ultra Low Power

ESP32 draws 1.2W while mining. That's less than a phone charger. Solar, wind, USB — if it produces 1.2W, it can mine Quartz.

🛡️

Quantum-Safe Wallets

WOTS+ hash-based signatures. Immune to Shor's algorithm. No elliptic curves to break when quantum computers arrive.

📡

ESP-NOW + LoRa Mesh

ESP-NOW for LAN clusters (~200m, ~15 TPS ceiling, zero extra hardware). LoRa for WAN backbone (2–15km, off-grid). Mine with no internet at all.

🧅

Tor Hidden Service

Node reachable via Tor onion address. Privacy at the network layer — the strongest opsec for IoT money.

🔧

Open Source

Firmware, protocol spec, reference node — all MIT licensed. No closed-source consensus, no proprietary tooling.
