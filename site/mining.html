CrystalHash 🔬

The proof-of-work algorithm that makes ESP32 the only viable mining hardware.

How it works

# Phase 1: AES-256 fills 256KB scratchpad
# Uses ESP32 hardware crypto accelerator
scratchpad = aes_256_ctr(block_header, nonce)

# Phase 2: 64 rounds of memory-hard mixing
for round in range(64):
    idx = hash(state) % (256KB / 32)
    state ^= scratchpad[idx]
    state = sha256(state)

# Phase 3: Physical Unclonable Function
# Flash cache timing — unique per chip
puf = measure_flash_timing()
state ^= puf

# Phase 4: Final hash
return sha256(state + nonce)

Why you can't cheat

🚫

Anti-ASIC

256KB scratchpad is too small to justify custom silicon, and the PUF requires physical ESP32 chips.

🖥️

Anti-GPU

Memory access pattern doesn't map to GPU parallelism. Per-thread 256KB is wasteful on VRAM architecture.

💡

Anti-CPU

Software AES/SHA on desktop CPUs is slower than ESP32's dedicated hardware for this chained pattern.

Quantum-Safe & Hardware-Bound 🛡️

Two technologies no other cryptocurrency combines at this price point.

🔬

PUF Mining

Every ESP32 chip has a unique silicon fingerprint from manufacturing variations in SRAM cells. This Physical Unclonable Function (PUF) generates a device-specific key that is:

  • Impossible to clone — unique per chip
  • Impossible to simulate — requires physical silicon
  • Stable — fuzzy extractor corrects bit drift
  • Mixed into every block hash — GPU can't compete

→ Mining is physically impossible without a real ESP32

⚛️

WOTS+ Quantum Wallets

Quartz uses hash-based signatures instead of elliptic curves. WOTS+ (Winternitz One-Time Signatures) with Merkle trees provide:

  • Immune to Shor's algorithm — the quantum attack that breaks RSA, ECC, and Ed25519
  • Only needs SHA-256 — no exotic math, battle-tested
  • 256 signatures per address — Merkle tree aggregation
  • ~128-bit classical security — 64-bit post-Grover (still infeasible)

→ Your wallet survives the quantum computing era

ESP32-Only Mining 🔒

Hardware attestation prevents PC/emulator mining. Only real ESP32 silicon earns rewards.

🔑

eFuse Key

Each ESP32-S3 has a factory-burned key in silicon. Cannot be read by software, JTAG, or firmware. Only the hardware HMAC engine can use it.

✍️

Block Co-Signing

Every mined block needs an Ed25519 signature from the device's private key (encrypted NVS). A PC can find nonces fast but can't sign blocks.

⚖️

Slashing

Double-signing at the same height produces verifiable evidence → permanent ban + forfeited rewards. Makes cheating irrational.

⏱️

Timing Protection

Blocks arriving faster than ESP32 hardware can compute = auto-ban. Even with a PC doing PoW, the ESP32 can only sign so fast.

Can a PC emulator mine Quartz?

Without attestation: Yes — a PC with AES-NI is ~100x faster than ESP32. It would dominate.

With attestation: No. The PC can find nonces, but can't produce the eFuse-backed signature. The ESP32 must physically sign each block.

Extracting the eFuse key requires decapping the chip and electron microscopy (~$10K+ per chip). Not economically viable.
