Security Economics: Attack Cost vs Network Value

The right question isn't "how much does an attack cost in absolute terms?" but "how much does it cost relative to what you'd gain?"

Bitcoin (2009) Bitcoin (2026) Quartz (500K miners)
51% attack cost ~$5K (GPUs) ~$7B (ASICs + power) ~$3.75M (250K ESP32s)
Network value ~$0 ~$1.2T ~$100M (projected)

The key insight:

Quartz at 500K devices has a 6x better attack-cost-to-value ratio than Bitcoin has today — 3.75% vs 0.6%. An attacker must spend more relative to what they'd gain. And unlike Bitcoin, where hashpower can be rented in minutes, a Quartz attack requires physically acquiring and enrolling hundreds of thousands of devices over months.

Why this scales:

Bitcoin wasn't born with $7B security. In 2009, a few thousand dollars in GPUs could have 51%-attacked it. Security grew with adoption. Quartz follows the same flywheel — more devices = higher attack cost = more valuable network = more incentive to stay honest. The difference is Quartz's flywheel runs on physical hardware ($15, 0.5W) instead of energy ($3,000, 3,000W).

The Honest Assessment

What's genuinely strong:

The PUF + no-fallback design means there is no software path to a mining key. Every valid block requires a physical ESP32 that performed a cold boot. An attacker cannot shortcut this with computation alone.

What's not yet production-ready:

Development devices (including our M5Stack Core) do not have flash encryption or secure boot burned. An attacker with physical access can read NVS or replace firmware. Production devices must have eFuses burned at provisioning time. User self-provisioning (not factory) keeps the network decentralized — no single entity holds all signing keys.

The scaling reality:

Bitcoin wasn't born with $7B security — in 2009, a few thousand dollars in GPUs could have attacked it. Security grew with adoption. Quartz follows the same trajectory, but the flywheel runs on physical hardware ($15 per device, 0.5W power) instead of energy ($3,000 ASICs, 3,000W). At 500K miners, Quartz's attack-cost-to-value ratio (3.75%) is actually better than Bitcoin's today (0.6%).
