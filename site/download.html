📜 Flash Command

After downloading, flash with esptool:

python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash 0x1000 bootloader-v066.bin 0x10000 partition-table-v066.bin 0x20000 quartz-app-v074.bin
Already flashed before? Just flash the app binary:
python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash 0x20000 quartz-app-v074.bin

Quartz Miner v073 — ESP32-S3

OLED display support — device ID, battery status, animated mining indicator. USER button cycles screens (ID → Mining → Fleet → Payment). Heltec V3 + LilyGO T3 auto-detected.

Download App Bootloader Partitions
python -m esptool --chip esp32s3 --port COM6 --baud 460800 write_flash 0x0 bootloader-s3-v066.bin 0x10000 partition-table-s3-v066.bin 0x20000 quartz-app-s3-v074.bin
Full reset (wipe, then re-flash): python -m esptool --chip esp32s3 --port COM6 erase_flash — then run the flash command above. Update (keep wallet): flash only 0x20000 quartz-app-s3-v074.bin
