📜 Flash Command

After downloading, flash with esptool:

Easiest: save flash_esp32.py into the same folder as the bin, then run: python flash_esp32.py — unplug the board, plug it back in, and it flashes itself.
Manual: python -m esptool --chip esp32 --port COM6 --baud 460800 write_flash 0x0 quartz-esp32-merged-v0892.bin
Already flashed before? Just flash the app binary:

Quartz Miner v089.2 — ESP32-C3

For ESP32-C3 boards (C3 DevKitM, C3 SuperMini, etc. — headless, serial console). v089.2: 📊 stats CCCD added — wallet address + live stats display after connect (the missing descriptor had dead-ended both). v089.1: 🔧 GATT table rewritten to Bluetooth spec — the service was malformed since day one and invisible to every client that ever connected (advertising kept working and masked it). Serial now logs service failures by name. v089: 🔧 boot-order fix — the entropy gate saw "no radio" with WiFi deferred and killed the setup task at boot (BLE never advertised; board looked alive but was not). BLE now comes up before the gate and the gate recognizes BT as a radio. v088: 📡 BLE owns the radio during setup — WiFi/portal deferred until the seed is confirmed (120s fallback): the coex arbiter was accepting advertising while giving it zero airtime; two independent scanners confirmed silence. v087: 📟 BLE status in the setup banner + self-heal. v086: 📻 payload-overflow fix (UUID in ADV packet, name in scan-rsp). v084: 📡 BLE during first-boot seed setup. v083: 🪡 ble on opens a 5-min BLE pair window — pair the app for seed setup + live miner stats on confirmed boards; relay arming survives reboots; console answers unknown commands. v082: relay auto vending mode. v081: pay-to-trigger relay, fast/safe + invert.
